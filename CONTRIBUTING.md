# Contributing

Use the issue forms for reproducible bugs and feature proposals. Include the 4789 build, iPhone and
iOS versions, sideloading method, expected result, and actual result.

Never attach an IPA signed with your account, a settings export, a password, key, token,
credential-bearing URL, private username, or personal-library screenshot.

The application-source contribution guide will live in the separate public source repository once
that audited repository opens.
