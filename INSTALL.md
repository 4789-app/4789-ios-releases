# Install 4789 for iPhone

The first public beta is not available yet. When it is ready, download only from this repository's
Releases page or the official source feed linked from `https://4789library.com/install`.

## Choose a sideloader

- [SideStore official installation guide](https://docs.sidestore.io/docs/installation/install)
- [AltStore official documentation](https://faq.altstore.io/)
- [Sideloadly official website and guide](https://sideloadly.io/)

Follow the sideloader's current instructions, import the verified `4789.ipa`, and sign it with your
own Apple Account. The sideloader and Apple handle signing; the Apple Account is never entered into
or received by 4789.

## Finish on iPhone

1. Enable Developer Mode if iOS requests it.
2. Trust the locally created developer profile when iOS requests it.
3. Open 4789.
4. Add a compatible manifest or install URL, a public Letterboxd/MDBList collection, or local files.
5. Activate optional features only when wanted; any required credential is requested at activation
   and stored in Keychain.
6. Export settings to Files/iCloud Drive after setup.
7. Refresh the signed app before its provisioning period expires.

## Important

- Free Apple Personal Team signing normally expires after seven days and permits only a small number
  of development apps.
- Refresh or update over the installed app. Do not delete it during a routine update.
- Export settings before any unavoidable removal.
- Never post passwords, keys, tokens, complete private URLs, or settings exports in an issue.
