## What it does

4789 brings compatible catalogs, public Letterboxd and MDBList collections, local files, and
downloads into one poster-first library. Choose a title, review its context, see the playable
options returned by services you connected, then watch in the built-in player or continue on a
supported television.

4789 supplies software, not media, streams, credentials, or an add-on directory. People connect
services and files they are authorized to use.

The first verified release will contain:

- an immutable versioned IPA and stable `4789.ipa` alias;
- `SHA256SUMS.txt`;
- an AltStore/SideStore-compatible source feed;
- release notes, exact build metadata, and known limitations; and
- signed-out download verification against the published checksum.

The audited application source will be published separately in `4789-app/4789-ios` only after its
secret, dependency-license, asset-rights, and public-build isolation reviews pass. This release
repository contains documentation and release assets, not the application source checkout.
