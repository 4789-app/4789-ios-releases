# 4789 for iPhone

**One beautiful library. One place to press play.**
</div>

**The first public beta is being prepared. No IPA has been published yet.**

iOS 26 or later · No jailbreak · No 4789 account · User-signed IPA

4789 brings compatible catalogs, public collections, local files, and downloads into one library.
Choose a title, review playable options from services you connected, then watch in the built-in
player or continue on a supported television. Connect services and files you are authorized to use.
4789 supplies software, not media or credentials.

An IPA does not install by opening it in Safari or Files. Sign it with your chosen sideloader and
your own Apple Account, then refresh before its signing period expires. Follow the installation
guide before downloading a future release.

This repository contains release documentation and release assets, not the application source
checkout. Application source publication is separate and remains subject to its existing reviews.
